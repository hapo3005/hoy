# RT-009 — Trademark Clearance Search Protocol

Purpose: produce an investor-/buyer-grade trademark evidence packet before HOY files or claims exclusivity.

## A. Databases / territories

Required search sets:
1. TMview / EUIPO — EU trade marks + participating national offices.
2. OEPM — Spanish national trademarks and trade names.
3. WIPO Global Brand Database / Madrid Monitor — international registrations/designations relevant to Spain/EU.

A Google/web search is **not** a substitute for official registry clearance.

## B. Query set

Run each query as exact + contains + fuzzy/similar where available:
- HOY
- HOY LA MANGA
- HOY GASTRO
- HOY LIFESTYLE
- HOY WORKS
- HOY SAFE
- MIRA HOY
- visual/logo search for the current HOY icon

Also search:
- marks with HOY as first/dominant element;
- phonetically/visually similar short marks;
- Spanish-language equivalents/compound marks only where counsel considers confusion plausible.

## C. Goods/services scope

Working high-priority classes:
- 9 — downloadable software/apps;
- 35 — advertising/business information/marketplace/intermediation functions actually provided;
- 42 — SaaS/software/technology services;
- 43 — restaurant information/reservation functions actually provided.

Conditional:
- 41 — entertainment/event information/booking;
- 39 — travel/transport information/arrangement.

Do not assume Nice class identity is required for conflict: reputation, complementary services, market proximity and wording matter.

## D. Record every live candidate

For every potentially relevant record capture:
- registry/source;
- mark;
- word vs figurative;
- application/registration number;
- owner/applicant;
- territory;
- priority/application/registration date;
- status;
- classes;
- exact goods/services;
- dominant elements;
- visual/phonetic/conceptual similarity;
- overlap with HOY services;
- reputation/market-use evidence;
- preliminary risk: RED / AMBER / GREEN;
- counsel conclusion;
- mitigation.

Never infer ownership or current validity from a news/site mention alone.

## E. Absolute-ground review

Counsel must separately answer:
1. Is `HOY` descriptive, laudatory, customary or otherwise non-distinctive for any proposed goods/services because it means “today” in Spanish?
2. Does the actual HOY proposition (“today/now/current local intent”) make the descriptiveness link direct enough for refusal?
3. Would acquired distinctiveness ever be required, and if so is there sufficient pre-filing evidence? Do not assume yes.
4. Does `LA MANGA`, `GASTRO`, `LIFESTYLE`, `WORKS` or `SAFE` materially add distinctiveness? Default internal assumption: limited.
5. Does the current graphic treatment create sufficient figurative distinctiveness, and how narrow would the resulting protection be?
6. What disclaimer/limitation/specification strategy is appropriate, if any?

## F. Relative-ground review

For each senior candidate answer:
- identical/similar sign?
- identical/similar/complementary goods/services?
- relevant public?
- trade channels/geography?
- conceptual overlap?
- enhanced distinctiveness/reputation?
- likelihood of confusion/association?
- opposition/infringement exposure?
- coexistence feasible?

Known-market-use signals, including Spanish media use of `HOY`, are only search priorities until exact registry evidence is attached.

## G. Filing architecture decision

Clear independently:
1. `HOY` word mark;
2. current/final HOY figurative mark;
3. any slogan selected for protection;
4. invented house/master mark.

Do not allow a green figurative search to be misrepresented as a green word-mark search.

## H. Evidence packet naming

Store under legal data room:
- `RT009_TMVIEW_HOY_<date>.pdf`
- `RT009_OEPM_HOY_<date>.pdf`
- `RT009_WIPO_HOY_<date>.pdf`
- `RT009_LOGO_IMAGE_SEARCH_<date>.pdf`
- `RT009_COUNSEL_CLEARANCE_MEMO_<date>.pdf`
- `RT009_FINAL_GOODS_SERVICES_<date>.xlsx/pdf`
- `RT009_FILING_RECEIPTS_<date>.pdf` only after approved filing.

## I. Stop rules

Stop filing preparation and escalate if:
- exact/near-identical live mark appears in core classes/services;
- a reputed senior mark could reach HOY despite class differences;
- counsel considers absolute refusal likely;
- owner identity/status is ambiguous;
- the filing specification would require claiming services HOY does not provide.

## J. F0-M rule

RT-009 does not pass F0-M merely because a search was performed. It passes only after search evidence, legal interpretation, filing/brand architecture and asset-control treatment are all reconciled.
