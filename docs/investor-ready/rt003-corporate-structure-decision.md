## Working recommendation

Use a **German GmbH as HOY Parent** if the founder can support the formation mechanics and the proof-round financing plan. The Parent should be the single investee and own/control the core HOY asset perimeter.

### Parent should own/control
- HOY Core software and repositories
- HOY Gastro / Lifestyle / Works software modules
- Local Business Graph / schemas / matching logic
- Evidence Engine / analytics taxonomy
- Region OS and operational playbooks
- brand, trademark applications, domains and social identities
- data structures, provenance/freshness history and derived signals to the extent legally owned/licensed
- central supplier/customer/partner contract templates
- shares in any later local operating subsidiary

### Parent should not delegate ownership of core IP to a Spain OpCo
A future Spain OpCo, if required, should be operational: local employment, contracting, sales/operations and local compliance. Core IP should remain at Parent and be made available under documented intercompany licence/services arrangements where required.

## Why Germany is the working default
1. Founder/management base is currently Germany.
2. Funding strategy is private/strategic and not dependent on Spanish subsidy structures.
3. A German Parent gives one clean entity for equity, IP, governance and later transaction diligence.
4. The German GmbH is a conventional limited-liability corporate form; statutory minimum share capital is EUR 25,000. For a cash formation, registration requires the statutory minimum paid-in amount under GmbHG §7.
5. Spanish activity still requires a separate permanent-establishment / VAT / payroll / employment review based on the actual operating facts; the Parent choice must not be used to assume Spanish tax obligations away.

## UG fallback
A UG (haftungsbeschränkt) is an acceptable **liquidity fallback**, not the preferred investor-ready target. If used, the formation plan should include an explicit path to GmbH once capital permits. Do not present UG status as a blocker by itself, but avoid unnecessary conversion work if the proof-round can support a GmbH directly.

## Cap-table baseline
Until signed evidence says otherwise:
- Founder: **100% pre-financing**
- Investors: 0%
- Employee/option pool: 0% (do not create a pool before a hiring/financing need is defined)
- SAFEs/convertibles/side letters/equity promises: **none known — must be confirmed in signed disclosure**

Illustrative dilution for a EUR 75,000 equity investment, before any option pool:
- EUR 650k pre-money → investor 10.34%, founder 89.66%
- EUR 700k pre-money → investor 9.68%, founder 90.32%
- EUR 800k pre-money → investor 8.57%, founder 91.43%

These are scenario calculations only, not a financing commitment or valuation proof.
