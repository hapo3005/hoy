## Purpose

Record where generative-AI assistance is part of HOY's creation/provenance story so a buyer can distinguish founder-owned project work, third-party/open assets, operational data and AI-assisted drafting.

This register does not make a legal conclusion about copyrightability or ownership. Those questions remain part of founder-IP / chain-of-title sign-off.

## Provenance principles

1. **AI assistance is not hidden.** Buyer DD should be able to understand which work was AI-assisted.
2. **Repository authorship is not the same as legal chain of title.** Technical Git provenance is strong, but founder IP must still be transferred/licensed/contributed to the sale entity using the tax/legal-approved mechanism.
3. **AI-assisted research does not cleanse upstream rights.** Every material external factual/media input remains subject to source-rights and privacy controls.
4. **Synthetic output is never market proof.** No AI-generated lead, response, testimonial, payment intent or usage event counts toward G2 Actual Proof.
5. **No third-party confidential code/data should be assumed licensed merely because it was processed by an AI tool.** Any such input, if found, must be isolated and reviewed.
